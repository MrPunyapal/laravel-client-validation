# Changesets

This folder is managed by [changesets](https://github.com/changesets/changesets).

- Run `npm run changeset` to describe your changes and pick version bumps.
- Run `npm run version` (or let the Release workflow do it) to consume changesets, bump versions, and update CHANGELOGs.
- Run `npm run publish` to build and publish changed packages to npm.
